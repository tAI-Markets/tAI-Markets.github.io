Protocol

A clearing house for inference

Providers collateralize, mint, and deliver. The clearing house stands between every trade: novation, routing, and settlement on-chain.

01 / COLLATERAL

Provider locks USDC

Per-provider vaults at a 150% collateral floor back every minted token.

02 / MINT

tModel issued

One tModel token = one million inference tokens, tradeable as an ERC-20.

03 / REDEEM

Holder burns for inference

The routing engine assigns the request by Service Factor σ — quality, latency, cost.

04 / SETTLE

Delivery & clearing

Provider delivers; 5% fee clears to the treasury. PLR backstop completes failed deliveries.

Properties

Why it holds

Fungible inference

Inference from any provider standardizes into one ERC-20 per model. A tGLM5 token is a tGLM5 token, whoever served the compute.

Overcollateralized

Providers lock 150% in USDC to mint. Keepers liquidate below the floor, so redemption stays guaranteed.

Provider of last resort

If no provider can serve a redemption, the PLR module buys replacement inference, keeping settlements whole.

Oracle-priced

The index mirrors the live open inference market on-chain, so tModel prices track real compute costs.
