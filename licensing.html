What's open vs. licensed

  • MIT (open): SDK rim — contract ABIs, shared types, agent demo, dashboard widgets. Integrate freely, forever.
  • BUSL-1.1 (source-available): protocol core (clearing house contracts) and gateway server. Read, fork, test on testnets; production requires a license.
  • Automatic: the code converts to Apache-2.0 at each release's 4-year change date, per standard BUSL terms.

Protocol economics (independent of licensing)

Every redemption settled through the clearing house pays a 5% settlement fee to the DAO treasury — enforceable on-chain, identical for every participant. Provider collateral sits in per-provider vaults at ≥150%. The commercial license covers operating the software; the protocol fee is the network's own revenue.
